# 🏏 IPL Data Analysis using Apache Spark

## 📌 Project Overview

This project performs IPL data analysis using **Apache Spark and PySpark**. The analysis works with IPL match and ball-by-ball datasets to explore match-level and player-level information.

The project demonstrates how PySpark can be used to create Spark sessions, define structured schemas, load large datasets, and perform data analysis efficiently.

## 🛠️ Technologies Used

- Python
- Apache Spark
- PySpark
- Databricks
- Spark SQL

## 📂 Dataset

The project uses IPL datasets containing:

- Ball-by-ball match information
- Match details
- Teams
- Seasons
- Venues
- Toss results
- Match winners
- Player information
- Runs and extras
- Wickets and dismissal information

## 🔍 Key Features

- Created a SparkSession for IPL data analysis
- Defined structured schemas using PySpark Data Types
- Loaded ball-by-ball IPL data using PySpark
- Loaded match-level IPL data using PySpark
- Analyzed batting, bowling, runs, extras, and wickets
- Worked with match, season, team, venue, and player attributes

## 🚀 Project Workflow

1. Initialize Apache Spark
2. Import PySpark libraries and functions
3. Define schemas for IPL datasets
4. Load ball-by-ball data
5. Load match data
6. Perform data analysis using PySpark
7. Extract meaningful insights from IPL data
